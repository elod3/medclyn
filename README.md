# MedClyn — copie statică a site-ului

Mirror complet (offline-safe) al site-ului https://www.medclyn.com, făcut pe 6 oct 2026.

- Pagini HTML: `*.html` (inclusiv blog, video, galerie foto, portofoliu)
- Imagini: `uploads/`, `img/`
- CSS/JS: `css/`, `js/`

Nu funcționează în copia statică: coșul de cumpărături, contul de utilizator,
formularele (necesită PHP pe server). Video-urile sunt embed-uri Vimeo (externe).
